❤️ Love Curtain

An interactive, romantic text curtain animation built with HTML, CSS, and JavaScript.

✨ Live Demo: "View Love Curtain" (https://saurav56295.github.io/love-curtain/)

Move your cursor near the hanging text strands and watch them bend and swing aside like a real curtain, then gently settle back into place.

🌟 Features

- ❤️ Repeating text strands displaying "I Love You My Sweetheart"
- 🖱️ Interactive, cursor-responsive animation
- 🎐 Smooth swinging and curtain-like movement
- ✨ Lightweight and browser-based
- 📱 Designed as a creative front-end experiment

🛠️ Built With

- HTML5 — Page structure
- CSS3 — Styling and visual presentation
- JavaScript — Animation and interaction logic

🚀 Run Locally

1. Clone this repository:
   
   git clone https://github.com/Saurav56295/love-curtain.git

2. Open the project folder in Visual Studio Code.

3. Open "index.html" in your browser, or use the Live Server extension.

4. Move your cursor near the text strands to explore the animation.
